# 블루 아카이브 RE:LIVE v1.0

블루 아카이브 프롤로그를 3D로 다시 만든 비영리 팬게임의 **정식 배포판**입니다.

## 다운로드 및 실행

1. Windows PC에서 [BlueArchive_RELIVE_v1.0.zip](https://github.com/FIZZ-DK/BA-Demo/releases/latest/download/BlueArchive_RELIVE_v1.0.zip)을 다운로드합니다.
2. ZIP 파일의 압축을 전부 풉니다.
3. `BlueArchive_RELIVE_v1.0` 폴더 안의 `BlueArchive_RELIVE.exe`를 실행합니다. 설치는 필요 없습니다.

실행 파일과 데이터 폴더를 함께 보관해 주세요. 자세한 조작은 동봉된 `README.txt`에 있습니다.

프롤로그를 **PROLOGUE END**까지 완료하면 장면 선택과 새로운 타이틀 화면이 열립니다.

- 실행 환경: Windows 10 / 11 (64비트), DirectX 11 지원 그래픽카드, 저장 공간 약 1GB
- [정식 배포판 릴리스 안내](https://github.com/FIZZ-DK/BA-Demo/releases/tag/v1.0)

블루 아카이브의 캐릭터·세계관·음성·그림의 권리는 원 저작권자(NEXON Games·Yostar)에게 있습니다.
